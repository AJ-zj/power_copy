# 技术边界

> 这份文档记录**明确未实现的范围**。
>
> 目的是避免把工程骨架误认为完整产品，也避免把「能跑」当成「能上线」。

## 数据采集

### 未实现

| 项目 | 说明 | 风险 |
|---|---|---|
| robots.txt 自动检查 | 当前靠人工确认 | 可能违反网站条款 |
| 持续采集授权 | 仅为工程技术验证 | 不可用于生产采集 |
| 完整 SSRF 防护 | DNS 解析检查、网络出口限制属 Harness 阶段 | 内网地址可能被访问 |
| 定时增量调度 | 无调度器 | 需人工触发 |
| 采集限流 | 只有简单间隔，无令牌桶 | 高频采集会压垮目标站 |
| 跨进程协调 | 单进程顺序处理 | 多进程会重复采集 |

### 已实现

- ✅ 精确域名白名单
- ✅ 禁止自动重定向
- ✅ 禁用环境代理
- ✅ 响应大小限制（2 MiB）
- ✅ 网络超时（10s）
- ✅ 错误分类（HTTP / 网络 / 超时 / 大小）
- ✅ 有限重试与指数退避
- ✅ 全局请求预算
- ✅ 403/429 暂停整个 run

### 合规提示

采集前必须人工确认：

1. 目标网站的 `robots.txt`
2. 网站使用条款
3. 企业内部数据权限
4. 是否需要书面授权

`config/ingestion_approval.example.json` 是**操作员确认记录**，不是自动权限证明。

## 版本管理

### 未实现

| 项目 | 说明 |
|---|---|
| 迁移工具 | 无 schema migration，旧库需人工处理 |
| 删除/撤回 | 政策废止只能靠新版本表达 |
| 版本回滚 | 无 `rollback to version` 命令 |
| 分布式锁 | 靠 SQLite `BEGIN IMMEDIATE` 串行化 |
| 法律效力判断 | 无法判断政策是否废止 |
| 生效日期解析 | 不区分发布日期与生效日期 |

### 已实现

- ✅ 身份/版本/观测三元组
- ✅ A→B→A 完整历史
- ✅ 内容哈希去重
- ✅ fetch_id 幂等
- ✅ 迟到事件拒绝
- ✅ 事务原子性

### 重要限制

**「最新观测版本」不等于「当前法律有效」。**

这是两个完全不同的概念：

- 最新观测版本 = 本地库里 version 最大的那个
- 当前法律有效 = 现实中是否还在生效

后者需要人工核验或接入官方废止清单，当前**完全没做**。

每次查询结果的 `notice` 字段都会声明这一点：

```text
仅代表本地库中最近观测到的版本，未核验当前法律效力、适用范围及网站最新状态。
```

### 安全边界

工作台**仅供本机使用**：

```python
app.add_middleware(TrustedHostMiddleware,
                   allowed_hosts=["localhost", "127.0.0.1", "[::1]", "testserver"])
```

**不要直接暴露到公网**。上公网前至少需要：

1. 用户认证
2. HTTPS
3. 速率限制
4. 审计日志

## 依赖风险

| 依赖 | 用途 | 风险 |
|---|---|---|
| `pypdf` | PDF 解析 | 未做安全审计，不可信 PDF 应在沙箱解析 |
| `beautifulsoup4` | HTML 解析 | 相对成熟 |
| `openai` | LLM 客户端 | 官方 SDK |
| `fastapi` / `uvicorn` | API | 生产需配反向代理 |

### PDF 解析隔离

当前 PDF 解析在**主进程**中运行。如果接受不可信上传：

1. 应在独立进程/容器中解析
2. 设置 CPU / 内存硬限制
3. 解析失败不能影响主服务

现在的 10 MiB / 100 页 / 100k 字符是**应用层检查**，不是进程资源限制。

### 诚实原则

本项目坚持：

1. 不把模拟数据描述为真实政府政策
2. 不伪造 HTTP 200 记录

5. 不把「未标注地区」说成「全国适用」
