### 三个审核发现，逐一核实

我用脚本把每条发现与证据原文逐字比对，结论是**三条全部是误判**：

| 发现 | 审核意见 | 核实结论 |

| i1 | 「证据未提供 2024年4月18日通过、4月25日公布、7月1日施行等日期」 | ❌ **误判**。日期确实存在，但在切片的 `title` 字段里，不在 `exact_quote` 里。审核只把 `exact_quote` 给模型，所以模型看不到 |
| i2 | 「退出电力市场也应办理注册手续在证据中未见明确规定」 | ❌ **误判**。证据原文第五条明确写着「经营主体进入或者退出电力市场应当办理相应的注册手续」 |

## 三、修复的 3 个缺陷

### 缺陷 1：事实核查语料漏掉 `title`

**根因**：`corpus = "\n".join(e.exact_quote for e in ...)`，只取正文片段。

政策名称、发布机关、施行日期这些信息在切片的 `title` 字段中。
文案引用标题里的日期是完全合法的，但审核看不到 → 误判。

**修复**：新增 `_evidence_corpus()`，同时包含 `【政策标题】` 与
`【原文片段】`。字面回溯也使用同一语料。

**验证**：修复后 `2024年4月18日`、`2024年7月1日` 都在语料中。

### 缺陷 2：修订静默失败，无诊断信息

**根因**：`_revise` 有三处 `return None`，全都不记录原因：

```python
except Exception:
    return None            # ← 不知道为什么
if not raw:
    return None            # ← 不知道为什么
except Exception:
    return None            # ← JSON 解析失败，不知道模型返回了什么
```

用户只能看到「模型未能给出可用的订正结果」，无法判断是网络问题、
模型拒绝、还是格式不合规。

**修复**：
- 新增 `_last_revision_error`，每条失败路径都写明原因
- 新增 `_extract_json_object()`，容忍模型返回带前后缀的 JSON
  （如「好的，结果如下：{...}」），不再直接失败

**验证**：6 种输入（纯 JSON、前缀、后缀、代码块、无效、带额外字段）
全部正确处理。

### 缺陷 3：字数严重超标（1685 / 800）

**未修复**。这是真实 LLM 的已知限制：字数控制是提示词级的，不精确。
Mock 能精确是因为它做机械裁剪，真实模型做不到。

**第 2 次实验降到 1221 / 800**，仍超标 53%。这需要在人工验收时处理。

### 生成的文案

**标题**：工商业企业参与电力市场前，这些基本规则要了解

> 随着电力市场化改革推进，越来越多工商业用电企业开始关注如何参与电力市场交易。
> 根据《电力市场注册基本规则》（国家能源局印发）和《电力市场运行基本规则》
> （2024年4月18日经国家发展改革委第11次委务会通过，2024年4月25日国家发展
> 改革委令第20号公布，自2024年7月1日起施行），企业入市前需要了解以下几个
> 基本规则。
>
> **一、谁可以成为市场经营主体？**
> 参与电力市场交易的经营主体包括发电企业、售电公司、电力用户和新型经营主体
> （含新型储能企业、虚拟电厂、智能微电网等）。对工商业用电企业而言，就是以
> "电力用户"身份进入市场。
>
> **二、入市第一步：办理市场注册**
> 拟参与电力市场交易的经营主体应在电力交易机构办理市场注册，并对注册业务
> 信息以及相关支撑性材料的真实性、准确性、完整性负责。市场注册遵循以下原则：
> 1. 规范入市：在电力交易机构办理注册，确保材料真实、准确、完整；
> 2. 公开透明：电力交易机构公平公开受理各类注册业务，不得设置不合理和
>    歧视性条件，服务无差别，信息规范披露；
> 3. 全国统一：严格落实"全国一张清单"管理模式，注册业务流程、审验标准、
>    受理期限、公示要求全国统一规范；
> 4. 信息共享：经营主体可自主选择电力交易机构办理，无需重复注册，
>    实现"一地注册、各方共享"。
>
> **三、电力用户入市的两个基本条件**
> 按照《电力市场注册基本规则》，电力用户的基本条件是：
> 1. 工商业用户原则上全部直接参与电力市场交易，暂未直接参与市场交易的
>    工商业用户按规定由电网企业代理购电；
> 2. 具备相应的计量能力或者替代技术手段，满足电力市场计量和结算的要求。
>
> **四、参与电能量交易的行为规范**
> 根据《电力市场运行基本规则》，电能量交易由电力市场运营机构按照电力市场
> 运行规则组织实施，也可以由电力交易双方协商。经营主体在履行市场注册程序后，
> 方可参与电能量市场交易。
> 需要注意的是，规则明确：经营主体之间不得实行串通报价、哄抬价格以及扰乱
> 市场秩序等行为；不得滥用市场支配地位操纵市场价格；由多个发电厂组成的
> 发电企业进行电能量交易，不得集中报价。电能量交易应通过电力市场运营机构
> 校核后执行。
>
> **五、了解电力辅助服务**
> 经营主体应当按照有关规定提供用以维护电压、频率稳定和电网故障恢复等方面的
> 电力辅助服务。电力辅助服务分为基本电力辅助服务和有偿电力辅助服务……
>
> **温馨提示**：本文引用的是本地库中该政策的最新观测版本，这不代表该政策
> 现行有效，是否废止需以官方公告为准；文中政策适用地区未作指定，不代表全国
> 适用。企业参与市场交易前，建议以官方发布渠道的最新政策文件为准。

## 五、必须诚实说明的问题

### 1. 字数仍然超标

```text
目标：600–800 字
实际：1221 字（超标 53%）
```

真实 LLM 按提示词控制字数，不精确。**这需要人工精简后才能使用**。
Mock 模式的字数控制是机械裁剪，两者不可比。

### 2. 研究阶段有 1 个问题失败

```text
! 问题「国家政策对工商业电力用户进入电力市场的准入条件（如电压等级、
  用户类别、注册流程）有哪些具体规定？」提取候选事实失败：
  模型调用失败：Connection error.
```

网络中断导致该问题未提取。流程正确降级（`research_status=partial`），
其余问题正常完成。

### 3. `usage_incomplete = True`

有 1 次 API 重试，失败那次的用量未知。这是软预算应有的如实标记。

### 4. 事实支持性只是机器意见

`fact_support_llm_used = True`，8 条陈述由 LLM 判断为支持。
**这不等于专家确认**，必须经人工验收表逐条核对。

### 5. 政策时效性程序无法判断

《电力市场注册基本规则》原文写「有效期五年」（2024-09-13 印发）。
2029 年 9 月到期，目前仍在有效期内，但**需人工核实官方公告**。
